# Privacy Policy — Antigravity Tab Groups

**Last updated:** 2026-11-22

`Antigravity Tab Groups` collects, stores, transmits, or sells **zero** user data.

- **Minimal permissions**: Requests only `tabs` and `tabGroups` to open and organize agent tabs into labeled background groups (`Antigravity` / `AGY`).
- **No host permissions**: Does not request `<all_urls>` or read web page content, cookies, passwords, or browsing history.
- **No network requests**: Makes zero outbound network calls and contains zero analytics, telemetry, or third-party SDKs.
- **Local-only execution**: All tab-group actions run locally inside your Chrome browser via your user-approved local MCP connection (`chrome-devtools-mcp`).
